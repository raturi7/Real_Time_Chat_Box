# Real-Time Chat Box

A real-time browser-based chat application built with vanilla JavaScript, WebSockets, and SCSS.

## Features

- Instant messaging via WebSockets (no page refresh needed)
- Clean, responsive UI styled with SCSS
- Runs entirely in the browser — no backend framework required

## Tech Stack

- **Frontend:** JavaScript (ES6), HTML5, SCSS/CSS
- **Protocol:** WebSockets
- **Build:** None — open `index.html` directly

## Getting Started

### Prerequisites

- A modern browser (Chrome, Firefox, Edge)
- A local HTTP server (optional, for SCSS compilation)

### Run locally

```bash
git clone https://github.com/Raturi7/Real_Time_Chat_Box.git
cd Real_Time_Chat_Box/Source
# Open index.html in your browser
open index.html
```

## Project Structure

```
Real_Time_Chat_Box/
```
